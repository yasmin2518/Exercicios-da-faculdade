# Desenvolvimento Web


##  Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em Desenvolvimento Web, com o objetivo de praticar e aprimorar meus conhecimentos em HTML e CSS.

A proposta foi desenvolver uma página web, trabalhando conceitos de estruturação de conteúdo, estilização e organização de elementos.

##  Tecnologias utilizadas

- HTML5 – Estruturação da página.
- CSS3 – Estilização e layout.

##  Objetivos de aprendizagem

- Praticar a criação de páginas HTML.
- Aplicar estilos utilizando CSS.
- Trabalhar com seletores e propriedades CSS.
- Aprender a organizar arquivos de um projeto web.
- Desenvolver autonomia na construção de páginas.

## Como visualizar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.
4. Ou utilize a extensão Live Server para visualizar a página.

## Status do projeto

Projeto desenvolvido para fins de estudo e prática.

Este é um dos meus primeiros projetos na área de Desenvolvimento Web e representa parte da minha evolução acadêmica e profissional em Análise e Desenvolvimento de Sistemas.
